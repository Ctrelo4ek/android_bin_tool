# 编译工具链及其区别：
# 1. arm-linux-gnueabi-
#    - 适用架构：32位 ARM（ARMv4, ARMv5, ARMv6, ARMv7）
#    - 浮点支持：软浮点（不支持硬浮点）
#
# 2. arm-linux-gnueabihf-
#    - 适用架构：32位 ARM（ARMv7）
#    - 浮点支持：硬浮点（支持硬浮点）
#
# 3. armv8l-linux-gnueabihf-
#    - 适用架构：32位 ARM（ARMv8 32位模式）
#    - 浮点支持：硬浮点（支持硬浮点）
#
# 4. aarch64-linux-gnu-
#    - 适用架构：64位 ARM（ARMv8 64位模式）
#    - 浮点支持：硬浮点（默认支持硬浮点）

# NEON（高级SIMD）：
# - 用于多媒体和信号处理任务（图像处理、音频处理、视频编解码）。
# - 支持8位、16位、32位和64位整数，以及单精度浮点数。
# - 提供并行处理（SIMD：单指令多数据）。
# - 丰富的多媒体和信号处理指令集。
# - 16个128位寄存器（Q0-Q15），每个寄存器可以分为多个部分。
# - 优化多媒体和信号处理性能。

# VFP（向量浮点）：
# - 用于浮点运算（科学计算、图形处理）。
# - 支持单精度（32位）和双精度（64位）浮点数。
# - 提供标量和向量操作。
# - 浮点运算指令。
# - 32个64位寄存器（D0-D31），每个寄存器可以分为多个部分。
# - 提供硬件加速的浮点运算。

# arm-linux-gnueabi- 编译链
